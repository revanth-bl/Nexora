# Linux Official Resources

## Overview

The **Official Resources** section provides a curated collection of trusted documentation, manuals, books, websites, and learning materials maintained by the Linux community and software vendors. These resources are invaluable for learning Linux, staying updated with new features, troubleshooting issues, and exploring advanced topics.

Whenever possible, refer to official documentation for the most accurate and up-to-date information.

## Manual Pages (Man Pages)

The built-in Linux manual system provides detailed documentation for commands, system calls, libraries, and configuration files.

Example:

```bash
man ls
```

Search manual pages:

```bash
man -k network
```

---

## Info Pages

GNU Info provides more detailed documentation than traditional man pages.

Example:

```bash
info bash
```

# Useful Commands

Open a manual page:

```bash
man command
```

Example:

```bash
man chmod
```

Search manuals:

```bash
man -k ssh
```

Display command help:

```bash
command --help
```

Example:

```bash
grep --help
```

Open Bash documentation:

```bash
info bash
```
